Security & Architecture

Authentication logic, access rules and simulated system structure.

Protected System

Role-Based Access Control

Student cards are limited to public university areas.
Employee cards can access laboratories and staff zones.
Admin cards have full access to all locations.
Guest cards only allow temporary entrance access.

Authentication Workflow

Step 1 NFC reader scans card UID.
Step 2 System searches registered card database.
Step 3 Card status and role permissions are checked.
Step 4 Access is granted or denied.
Step 5 Authentication result is saved into logs.

System Architecture

NFC Card → NFC Reader → Authentication Layer → Access Control → Admin Dashboard
In a real environment, the frontend would communicate with a backend API and a cloud database.
This thesis prototype focuses on frontend simulation and system workflow visualization.

Security Notes

This project demonstrates the logic of an NFC-based authentication system. In a production environment, encrypted communication, backend verification, secure databases and real NFC hardware integration would be required.

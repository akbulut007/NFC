System Flow

NFC Card → NFC Reader → UID Validation → Role Check → Access Decision
The system checks whether the card is registered, active and allowed for the selected location.
Each authentication attempt is saved as an access log for later monitoring.

Engineering Thesis Explanation

This dashboard represents the control center of the NFC card management prototype. It gives an overview of registered cards, active users and access decisions. The project focuses on system design, authentication workflow and access control logic. In a production environment, this frontend would communicate with a backend service, a secure database and a physical NFC reader device.
